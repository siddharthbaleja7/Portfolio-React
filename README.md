# Personal Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript.

## Website

This repository contains the source code for my personal portfolio website.

## Project Structure

```text
Portfolio-React/
├── index.html
└── README.md
```

## Running Locally

Since this is a static HTML website, no React, Node.js, or build process is required.

Simply open `index.html` in a web browser.

Alternatively, you can run it with a local development server if preferred.

## Deployment

The website can be deployed directly as a static site using Vercel or any other static hosting service.

No build command is required.
